### 確認方法

- 296語：辞書サイトに限定した検索で見出しページのURLを特定 → そのページを取得 → 読み取り役のAIに見出し語・品詞・語義を報告させて確認（データ上の `access: page-fetch`）。言語ごとに別の作業エージェントが担当しました。**ページ本文を人が読んだ確認ではなく、AIによる読み取りの報告に基づきます。**
- 8語（英語：sacrifice, devotion, bondage, metamorphosis, oblivion, yearning, remembrance, memory）：検索結果に表示されたページ抜粋で確認（`access: search-excerpt`、v2.2 と同じ方法）。
- 英語は Cambridge Dictionary のページを取得できなかったため、追加語はすべて Merriam-Webster です。Merriam-Webster の発音表記は独自方式なので、発音記号は記録していません。
- 発音記号を記録できたのは追加語304語中12語（ドイツ語11・フランス語1）。ほかは「未確認」と表示します。
- カタカナ読みは目安です。ポルトガル語の -ção / -são は「サン」と表記しています（例：maldição＝マルディサン）。
- 取り込み後に全語の見出し語・読み・分類・候補名を一覧で目視しました。意味が逆に取れる候補（dishonor の「オナー」、disgrace の「グレイス」）は外しました。語義の日本語を1語ずつ辞書と突き合わせ直す再確認はしていません。

### 対比について

- 「辞書の対義語欄に例がある対比」6組（希望↔絶望、祝福↔呪い、自由↔束縛、勇気↔恐怖、誠実↔欺瞞、喜び↔悲嘆）の根拠は、v2.2 の調査で Larousse / Treccani の検索抜粋に表示された対義語欄です。**根拠はフランス語・イタリア語の1〜2項目ずつで、5言語すべてで対義関係を確認したわけではありません。** 画面にも「並ぶ語のすべてが互いに対義語というわけではない」と表示します。
- 指示書の例にあった「信頼↔疑念」「受容↔拒絶」は、辞書の対義語欄を確認していないので「物語上の対照」に入れています。

## 5. 既知の制約

- 語義の確認はAIによるページ読み取りの報告に基づくもので、誤読の可能性は残ります。気になる語は、各カードの「出典」リンクから辞書を確認してください。
- 陰の言葉には、強い否定的意味や、場面によって不適切になりうる語義を持つ語があります（例：英 bondage、独 Opfer）。気づいたものは「ニュアンス・注意」に記しましたが、網羅はしていません。
- 創作名と実在の人名・単語・商標との重複は未確認です。
- GitHub Pages への反映は、作業環境から確認できません。
