# v2.1「言葉から名付け」第1段階 — 実装・検証メモ

## 収録語と確認方法（2026-11-17）

「肯定・同意」「承認・認知」の20語（フランス語・ドイツ語・イタリア語・英語・ポルトガル語、各4語）。

| 言語 | 辞書 | 語 |
| --- | --- | --- |
| フランス語 | Larousse | oui / accord / assentiment / reconnaissance |
| ドイツ語 | Duden | ja / Zustimmung / Anerkennung / Beifall |
| イタリア語 | Treccani | sì / assenso / consenso / riconoscimento |
| 英語 | Cambridge Dictionary | yes / assent / accord / acknowledgment |
| ポルトガル語 | Priberam | sim / acordo / assentimento / reconhecimento |

- 各語は、上の辞書サイトに限定した検索で見出しページを特定し、検索結果に表示された見出し語の表記・品詞・語義を読んで確認した。出典URLはその見出しページ。
- **見出しページそのものを直接開いての確認はできていない**（作業環境から辞書サイトのページを取得できなかったため）。確認できたのは検索結果に出る範囲（定義の冒頭部分・品詞・一部の発音表記）で、ページ下部の用例や細かい語義区分までは見ていない。
- 日本語の説明は確認した内容を短く編集したもので、辞書本文の翻訳・転載ではない。
- 発音記号を確認できたのは13語（フランス語4語、ドイツ語の ja・Zustimmung、イタリア語の assenso・consenso・riconoscimento、英語4語）。残り7語（Anerkennung、Beifall、sì、ポルトガル語4語）は画面上で「発音：未確認」「カタカナ読み（目安）」と表示する。フランス語の発音記号は Larousse の学習者向け・対訳ページの表記、イタリア語は Treccani「Sinonimi e Contrari」の表記による。
- 創作名の候補63件と「印象」の文は編集上の提案で、辞書に基づくものではない。

`verify-browser-word-naming.cjs` は一連の確認の中で8回実行し、7回成功・1回失敗した。失敗した1回は全項目を通過したあと、最後の「コンソールエラーが0件」の確認で止まったもので、当時はエラー内容を出力しておらず原因を特定できていない。その後5回連続で再現しなかった。次に起きたときに内容が分かるよう、失敗時にコンソールエラーを出力するようにした。

主な確認内容：既存辞典の675件・検索・お気に入りが変わらないこと、原語ブロックに創作名が混ざらないこと、出典リンクが言語ごとの辞書を指すこと、重複IDや「未確認なのに確認済み扱い」を検証スクリプトが検出すること、絞り込みと検索、お気に入りが辞典と別キーで保存されること、作品への保存・バックアップ・復元、v2.0で作った作品（名前候補の欄を持たない）がそのまま開けること、390px・320px幅の表示。

## 未確認・既知の制約

- 実機のiPhone Safariでは未確認（PC上のスマホ相当表示で検証）。
- 「キャラ作成に送る」は、ガチャの既存の「設定だけ」モードに切り替えて名前欄に入れる方式。名前と設定を同時に自動生成するモードでは名前を指定できないため。
- 自由入力のテーマ検索は、登録済みカテゴリとその別名（「賛成」「ほめる」など）への対応づけと、登録語の意味・読みの部分一致。未登録の言葉を翻訳して探すことはしない。
- 創作名の長さは「音の数」の近似（拗音は1音、促音・長音・撥音は1音）。
- 第2段階以降（残り9カテゴリ、テーマ別コレクション、複数キャラへの一括命名）は未着手。カテゴリは画面上で「準備中」と表示している。
