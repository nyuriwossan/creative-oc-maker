# 一字名の欠損値表示の修正

基点：公開済み v1.5 の `c56ea3e`。この修正はローカルブランチ `codex/fix-null-name-display` のみで作成し、push・公開はしていない。

原因：一字名ではローマ字が `null` になる。結果カードが `esc(c.roman)` を無条件に呼び、`esc` 内の `String(null)` が文字列 `null` を作っていた。フル設定の詳細コピーも `"英字表記：" + c.roman` を無条件に連結していた。神話名の元の綴りが欠損した場合も、由来欄の見出しと値を適切に省略できなかった。

変更：`index.html` に任意の名前項目の値を判定する `hasNameValue` を追加。画面の読み・ローマ字行、名前だけコピー、詳細コピー、保存済み詳細、由来欄を組み立てる際、`null`・`undefined`・空文字・空白だけの値は項目ごと省略する。元の綴りがある神話名と、通常の姓名の表示は維持する。生成済み文字列からの一括置換は行わない。

検証：`verify-null-name-display.cjs` で報告された5人生成をEdgeで再現し、カード、名前だけコピー、詳細コピー、保存・再読込、フル設定、一字名以外の単名（神話名）、旧保存データ、通常の姓名を確認。任意項目の4種類の欠損値も確認し、全7項目が通過。既存の `verify-browser.cjs`、`verify-browser-v15.cjs`、`verify-kanji-myth.cjs`、`verify-naming.cjs`、`verify.cjs` も通過。旧生成系統は単独216,000件・5人組36,000件を検証した。
