# v1.5 漢字一字名・神話名の実装記録

開始点は GitHub `main` の `5062f45161fb680875e0b9f101aefed0641270d6`（v1.4）。作業ブランチは `codex/v1.5-kanji-mythology`。既存の v1.4 名前辞書と改修済みの UI・保存形式は保持した。GitHub への push と公開は行っていない。

## 実装

- 「名前の系統」に「漢字一字・苗字なし」「神話・伝承名」を追加。世界観、性別印象、キャラ設定とは独立して切り替える。名前だけ・フル設定・設定だけ、1人・5人、コピー、保存、再読込、キーボード操作に接続した。
- 一字名は 71 表記・84 読みを 68 字体群で管理。凛/凜、桜/櫻、鉄/鐵は各1抽選枠。標準モードでは辞書で確認した 81 読みだけを使い、創作読み3件は明示的な切替後のみ使う。例：朔（さく／ついたち）、凛・凜（りん）、蒼（標準：そう／あおい／あお、創作：そら）。姓は付けない。
- 神話名は 56 存在、別表示7件、伝承所属56件。内訳は神格47、英雄・伝説上の人物5、固有名のある幻獣4。ギリシア20、ローマ7、北欧8、エジプト8、日本6、メソポタミア6、アーサー王伝説1。例：ゼウス／ユピテルは対応する神格として別 ID、イナンナ／イシュタルは同一存在の別表示。幻獣の種族名や地名は入れていない。
- 神話名の出典、元の綴り、種別、伝承、短い説明を結果と保存済み詳細に表示する。出典の由来を OC の性格や世界観に強制しない。
- 候補不足を抽選前に調べる。新系統の5人生成では同一字体群・同一神話存在・同一表示名を重複させず、履歴は表示後にのみ確定する。失敗時は以前の結果と履歴を保持する。

## 抽選設計

一字名は字体群→表記→読みの順に抽選する。雰囲気未指定時、標準モードの67群は各 `1/67`、創作読みを含むモードの68群は各 `1/68` が基準。雰囲気一致時は従来の重み `1〜1.75` を字体群に一回だけ適用する。読みによって字の当選率は増えない。最近の最大20件の履歴は字体群単位で避け、候補が尽きた場合だけ古い順に緩和する。

神話名の「お任せ」は、まず種別を同じ確率で選び、次にその種別の伝承を同じ確率で選び、最後に存在を選ぶ。自動選択には収録数3件以上の区分だけを含める。現行辞書では神格・英雄・幻獣の3種が概ね各 `1/3`、神格内の6伝承が概ね各 `1/6`。英雄・幻獣の自動伝承はギリシアのみ。アーサー王伝説は明示選択で1人生成でき、5人生成では不足件数を伝える。別名の数は存在の抽選枠を増やさない。除外済み候補を毎回再評価する。

## 出典と編集判断

一字名の辞書読み81件は [Unicode Unihan 18.0.0](https://www.unicode.org/Public/18.0.0/ucd/Unihan.zip) の `kJapaneseOn` / `kJapaneseKun` と照合して全件一致した。検証に使用した ZIP の SHA-256 は `4c93ea9c1f636451729a840978f1667a53886af37ba854fdcce109721c63d43e`。Unihan は字の読みを示す資料であり、人名としての実例は保証しない。創作読みは `editorial` として分離した。

神話名の確認には [Theoi の神格一覧](https://www.theoi.com/Pantheon.html)、[英雄一覧](https://www.theoi.com/greek-mythology/heroes.html)、[幻獣一覧](https://www.theoi.com/greek-mythology/bestiary.html)、[デンマーク国立博物館](https://en.natmus.dk/historical-knowledge/denmark/prehistoric-period-until-1050-ad/the-late-iron-age/iron-age-gods/odin-tor-and-the-other-norse-gods/)、[國學院大學の神道事典](https://d-museum.kokugakuin.ac.jp/eos/)、[Oracc](https://oracc.museum.upenn.edu/amgg/Listofdeities/index.html)、[大英図書館のアーサー王解説](https://www.bl.uk/stories/blogs/posts/king-arthur-fable-fact-and-fiction)、[メトロポリタン美術館のバステト解説](https://www.metmuseum.org/art/collection/search/551774) などを用いた。各レコードの個別参照先は `data/kanji-myth-v1.5.json` の `sources` と `sources` キーから追える。

旧辞書と表示が重なる一字は25、新しい一字表示は46。神話名では旧辞書と「アーサー」の表示が重なるが、新辞書では伝承上の存在として独立した ID に登録した。字体差による重複は3群に統合し、別表記7件は同一存在の下に置いた。候補台帳には保留5件（例：朱／すざく、蘇／すい、隼／はやと）と除外3件（種族名・地名・ギリシア/ローマ神格の同一 ID 化）を記録した。

## 未実装・制約

- 神話の創作改変名モードは今回は実装していない。出典付き固有名の品質を優先し、利用できない設定欄も表示しない。
- 固有名の確認できた精霊は0件。現在の「幻獣・精霊の固有名」には幻獣4件のみを収録している。
- 英雄・幻獣の文化圏は主にギリシアに限られ、アーサー王伝説は1件のみ。候補不足の条件では5人生成を明示的に断る。
