### 目標（200〜300語）に対する不足

192語で、下限に8語届いていません。理由は確認方法の制約です。

- 作業環境から辞書サイトのページを直接取得できず（取得はすべて拒否されました）、確認は「辞書ドメインに限定した検索の結果に表示されるページ抜粋」に限られました。
- 1回の検索で確認できるのは2〜5語で、狙った語が結果に出ないことがあります。出なかった語は収録していません（例：フランス語 accueil / liberté、ドイツ語 Milde / Freiheit / Wille、英語 peace / concord / acceptance / kindness / trust / loyalty / sincerity / joy / happiness、ポルトガル語 clemência / bênção / alegria / confiança / liberdade / libertação / bondade / vontade など）。
- 英語が30語と少ないのは、Cambridge Dictionary の検索結果が対訳ページや関連語に散りやすく、見出しページの抜粋が得にくかったためです。

### 確認の範囲

- 全192語の `verification` は `access: "search-excerpt"`。確認したのは見出し語の表記・品詞・語義の冒頭までで、用例や細かい語義区分、ページ下部は見ていません。
- イタリア語の一部（tolleranza、clemenza、armonia、coraggio、liberazione、redenzione、emancipazione、riconoscenza）は類語辞典ページ（Sinonimi e Contrari）、audacia は Thesaurus ページ、英語 harmony は学習者向け辞典ページでの確認です。語ごとの「確認状況」に記載しています。
- ドイツ語 Frieden は Duden の見出しが「Friede, Frieden」。発音記号は Friede の形でしか確認できていないため未掲載です。
- 英語 praise は動詞の語義のみ確認（名詞の語釈は未確認と明記）。
- ポルトガル語 alforria は奴隷制の歴史に結びついた語で、その旨を注意書きに入れています。
- 創作名の候補は編集上の提案です。実在する人名・単語との重複は調べていません。気づいた重なり（165件）だけ記載しています。

## 2. 追加・変更した機能

- **言葉を探す**：テーマ語での逆引き（各カテゴリに別名を登録）、カテゴリのOR／AND、言語・ニュアンス・長さ・印象、検索場所（すべて／原語だけ／創作名だけ）、0件時の案内（同じ漢字を含むテーマ、条件を1つ緩めた場合の件数）、24語ずつのページ送り。未登録の言葉を翻訳して当てることはしません。
- **命名コレクション**：作品の `nameCollections`。項目は保存した名前（`nameIdeas`）を参照するので、1つの名前を複数のコレクションに入れられます。
- **複数キャラ命名**：意味カテゴリ（＋言語）またはコレクションから割り当て。確認画面で承認するまで図鑑は変更しません。読み・ローマ字は変更せず、名前のメモに由来と以前の名前を残します。
- **世界観連携**：作品の `nameUses` に、利用先ごとの名前と命名意図を記録。世界観の項目本文には原語の意味と命名意図を別の行で書きます。
- **互換性**：バックアップ形式3。形式2（v2.0／v2.1）のバックアップ、名前候補の欄を持たない v2.0 の作品を読めることをテストで確認。既存の辞典675件、v2.1 の20語・候補63件のID・内容は変更なし。依存ライブラリの追加なし。

## 3. v2.1 の「原因未特定のコンソールエラー」

原因を特定し、修正しました。

- v2.1 のコードで同じブラウザテストを10回実行し、10回目に再発。内容は `TypeError: Cannot read properties of undefined (reading 'length')`（`renderIdeas` ← `start`）。
- 原因：作品を開く処理が、キャラクターの読み込みを待つ前に「現在の作品」を差し替えていた。名前候補の欄を持たない古い作品（v2.0 で作った作品）では、その待ち時間のあいだ欄が無いままになり、ちょうどそこへ言葉データが届くと一覧の描画で落ちる。
- キャラクターの読み込みを700ms、言葉データを300ms遅らせて順序を固定すると、v2.1 では5回中5回再現。このとき画面にも「言葉のデータを読み込めませんでした」が出ます（利用者に見える不具合でした）。
- 修正：読み込みと補修が済んでから作品を公開する（`js/studio/app.js`）。名前辞典側も、欄がそろうまで「準備できていない」と扱う。同じ順序を固定した回帰テストを追加。

## 5. 既知の制約

- 実機の iPhone Safari では未確認（PC上の390px・320px相当の表示とタッチ操作で検証）。
- 語義の確認は検索結果の抜粋まで。公開前後に、気になる語は各カードの出典リンクから原典を見てください。
- 創作名と実在の人名・単語との重複は未調査。
- 複数キャラ命名の候補は無作為に並べ替えて割り当てます。音の印象や長さでの絞り込みは、この機能にはまだありません。
- 複数キャラ命名で候補なしの行に直接入力した名前は、由来を記録しません（名前だけ変更）。
- キャラクターの名前を変えても、読み・ローマ字は自動では変わりません。
- 世界観の項目やキャラクターを削除すると、その利用先の記録は次に作品を開いたときに外れます。
- 命名コレクションの書き出しはテキスト形式のみ。
