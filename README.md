# 創作OCメーカー v2.2

GitHub Pagesで動く静的な創作支援ツールです。キャラクターの生成に加えて、作品ごとのキャラ図鑑・身長比較・相関図・世界観設定を扱えます。登録・サーバー・APIキー・外部CDNは不要で、データはすべて利用者のブラウザ内に保存されます。

- 本体（5タブ）：<https://nyuriwossan.github.io/creative-oc-maker/>
- 名前辞典：<https://nyuriwossan.github.io/creative-oc-maker/dictionary.html>

## v2.0 の使い方ガイド

画面上部の「作品」で、いま扱う作品を選びます。キャラ・画像・身長比較・相関図・世界観は作品ごとにまとまります。最初は「マイ作品」が1つ用意されます。

| タブ | できること |
| --- | --- |
| 作成 | 従来のOCガチャ。結果カードや保存リストの「図鑑へ登録」で、いまの作品の図鑑へ送れます |
| 図鑑 | キャラの一覧・検索・絞り込み。設定の編集、複製、メモ、独自項目、衣装・表情の差分画像 |
| 身長比較 | 図鑑から選んだキャラを同じ縮尺で横並びに。並べ替え、背景色、目盛り、PNG保存 |
| 相関図 | 人物をドラッグで配置し、関係線を引く。同じ二人に複数の関係、複数の図、PNG保存 |
| 世界観 | 概要・地理・社会・組織・特殊設定・歴史・用語集と独自カテゴリ。キャラとの紐付け |

### はじめての流れ

1. 「作成」でキャラを生成し、気に入ったカードの「図鑑へ登録」を押す（「図鑑」の「白紙から作る」でも追加できます）。
2. 「図鑑」でカードを開き、身長や画像を足す。全部埋めなくても使えます。画像なしでも問題ありません。
3. 「身長比較」「相関図」で図鑑のキャラを選ぶ。
4. 「世界観」でテンプレート（現代・ファンタジー・SF・和風・白紙）を選び、組織や地域を書いてキャラと紐付ける。

### 身長比較の縮尺について

立ち絵は、画像の縦横比ではなく「頭頂部」と「足元」の2本の線で身長に合わせます。図鑑の差分にある「頭と足元を合わせる」で線をドラッグ（またはボタン・矢印キーで微調整）してください。帽子や角、足元の影は線の外にはみ出してかまいません。立ち絵がないキャラは仮のシルエット、身長が未設定のキャラは仮に160cmで表示します。

### 相関図の操作

- 「動かす」：人物をドラッグで配置。余白のドラッグで全体を移動、2本指（PCはCtrl＋ホイール）で拡大縮小。
- 「線を引く」：1人目をタップ → 2人目をタップ。分類（家族・恋愛・友情・敵対・主従・仕事・その他）、自由なラベル、向き（一方通行・双方向・なし）、色、線の種類を選べます。
- 線のラベルをタップ、または下の「関係の一覧」から再編集できます。

### データの連携

各タブはキャラをIDで参照します。図鑑で名前や身長を変えると身長比較・相関図にそのまま反映され、身長比較で入力した身長は図鑑のキャラに書き戻されます。キャラを削除するときは、身長比較・相関図・関係線・画像への影響を表示してから実行します。世界観の項目を消すと、キャラ側の紐付けだけが外れます。

### 保存とバックアップ（大事）

- 保存先はブラウザのIndexedDB（`ocMakerStudioV2`）です。画像は長辺1600pxまでに縮小して保存します。
- ブラウザのデータを消去したり、端末やブラウザを変えたりすると作品は引き継がれません。「管理」→「バックアップを書き出す（画像つき）」で作品ごとのJSONファイルを保存してください。iPhoneのSafariは長期間開かないサイトのデータを消すことがあるため、定期的な書き出しを勧めます。
- 「バックアップから復元する」は、常に新しい作品として取り込みます。既存の作品は上書きしません。
- プライベートブラウズなどIndexedDBが使えない環境では、その旨を表示したうえでメモリ上だけで動きます（ページを閉じると消えます）。

### v1系からの移行

従来の保存リスト（localStorageの `ocMakerSavedV1`）は変更も削除もしません。保存リストは「作成」タブにそのまま残り、各項目の「図鑑へ登録」または「管理」→「保存リストの◯件を図鑑へ取り込む」で図鑑へコピーできます（コピー後も保存リストは残ります）。

### 構成

既存のガチャ本体（`index.html` のインラインスクリプト）は、「図鑑へ登録」ボタン2か所とタブ用のマークアップ以外は変更していません。新機能は別ファイルです。追加の依存ライブラリはありません。

| ファイル | 役割 |
| --- | --- |
| `js/studio/core.js` | 共通データ構造・変換・縮尺計算・バックアップ形式（DOM非依存、Nodeで検証可能） |
| `js/studio/db.js` | IndexedDBの保存層（使えない環境ではメモリに切り替え） |
| `js/studio/nav.js` | 共通ナビゲーション（現在の作品カード＋5タブ）のマークアップ。`index.html` と `dictionary.html` が同じファイルを読み込むので、変更は両ページに反映される |
| `js/studio/app.js` | タブ、作品管理、共通UI、保存状態 |
| `js/studio/zukan.js` `height.js` `relation.js` `world.js` | 各タブ |
| `css/studio.css` | 新機能のスタイル（既存の配色変数を使用） |

## 言葉から名付け（v2.2）

名前辞典のページには2つのモードがあります。「名前を探す」は従来の辞典（675件）、「言葉から名付け」は外国語の実在語をもとに創作向けの名前を考えるモードです（翻訳機能ではありません）。「言葉から名付け」の中に3つの機能があります。

| 機能 | できること |
| --- | --- |
| 言葉を探す | 11の意味カテゴリ・5言語（仏・独・伊・英・葡）の192語から探す。意味の言葉（「希望」「優しさ」など）での逆引き、カテゴリの複数選択（いずれか／すべて）、言語・ニュアンス・創作名の長さ・音の印象、原語だけ／創作名だけの検索。0件のときは近いテーマと、条件をひとつ緩めた場合の件数を案内 |
| 命名コレクション | 保存した名前をテーマごとにまとめる（例：「全肯定する兄弟」）。言語の混在、並び替え、共通テーマ、メモ、コピー、テキスト書き出し |
| 複数キャラ命名 | 図鑑のキャラクターを複数選び、共通テーマの候補を1人ずつ割り当てて比較。重複の警告、個別編集。確認画面で承認するまで図鑑の名前は変えない |

保存した名前は「使う先を選ぶ」から、キャラクター名・姓/家名・国家/地域/都市名・組織/派閥名・用語集として送れます。語彙データは書き換えず、利用先ごとに「実際に使った名前」と「命名意図」を記録します。

### 語彙データの確認範囲（重要）

- 各語は 2026-11-17 に、言語ごとの辞書（Larousse / Duden / Treccani / Cambridge Dictionary / Priberam）に限定した検索で見出しページを特定し、**検索結果に表示されたページ抜粋**（見出し語の表記・品詞・語義の冒頭）を読んで確認しました。**見出しページを直接開いての全文確認ではありません**（作業環境から辞書サイトを直接取得できないため）。画面の各語の「確認状況」「確認方法」にも同じことを表示します。
- 抜粋で確認できなかった語は収録していません。日本語の説明は確認内容を短く編集したもので、辞書本文の翻訳・転載ではありません。
- 発音記号は、抜粋に表示されたものだけを載せています（192語中57語）。それ以外は「発音：未確認」「カタカナ読み（目安）」と表示します。
- 創作名の候補（579件）と「印象」は編集上の提案です。**実在する人名・単語との重複は確認していません**。気づいた重なり（実在の人名、外来語、商品名など）だけを候補ごとに記し、それ以外は「未確認」と表示します。

データは `data/word-naming-v2.json`（スキーマ `oc-word-naming` v2）。v2.1 の `data/word-naming-v1.json`（20語）は互換性確認のために残しています（20語と候補63件のID・内容は v2 でも同じ）。語の追加は `scripts/word_naming_words_v2.py` を編集して `python scripts/build_word_naming.py` を実行します。

```sh
python scripts/build_word_naming.py --check   # 生成物が最新か
node verify-word-naming.cjs                   # v2.1 の20語が v2.2 のコードでも検証・検索・保存できること
node verify-word-naming-v2.cjs                # 11カテゴリの語彙、検索（OR/AND・0件案内）、コレクション、一括割り当て、利用先、バックアップ
node verify-browser-word-naming.cjs           # 3機能の操作、世界観・図鑑への反映、復元、390px/320px
```

実装と検証の詳細、既知の制約は `reports/v2.2/implementation.md` にあります。

## 名前辞典の使い方

「名前辞典」で名称・読み・説明・別表記・原語を検索できます。50音の行、12ジャンル、小分類、用途（複数はOR条件）、印象で絞り込み、カードの詳細から確認状況と参考資料を見られます。36件ずつ追加表示します。コピーは名称と読みを一緒にコピーし、ブラウザで許可されない場合は選択用テキストを表示します。

お気に入りはこの端末のブラウザに保存します。お気に入りだけの一覧、読み順・登録順の切り替え、解除ができます。「この名前でOCを作る」を押すと、その辞典IDを検証し、名称・読みを**単名として固定**します。5人生成でも同じ名前の異なる設定を作れます。「設定だけ」では固定を一時停止し、従来の手入力を使います。「固定を解除」または条件リセットで解除します。辞典名での保存・詳細コピー・名前コピー・画像生成用プロンプト素材のコピーも使えます。

名前の詳細設定に「自然・古典モチーフ」を追加しました。ジャンルは複数選択でき、未選択なら全ジャンルです。初期用途は「候補すべて（おすすめ用途で絞らない）」。人物名・姓/家名・異名/コードネーム・組織/地名の編集上のおすすめでも絞れます。どの用途でも素材語を改変せず単名として使い、姓や読み・英字表記を作り足しません。性別は人物設定に使い、名称の男女適性を捏造しません。最近20件を避け、10個生成では同じ表示名を重複させず、候補が少なければ全候補を表示します。0件は他ジャンルに置き換えず条件変更を案内します。

## 保存の互換性

既存OC保存キー `ocMakerSavedV1` は変更しません。辞典のお気に入りは別キー `ocMakerDictionaryFavoritesV1` に `{version:1, ids:[...]}` を保存します。存在しなくなったIDは別名称へ置換せず通知します。保存領域の利用不可時は、辞典はメモリ内のお気に入りを利用し永続化不可を通知します。破損したOCレコードは表示時に除外し、自動で保存内容を書き換えません。

公開時の配信URLは同じオリジン・サブパスを維持してください。オリジンやブラウザが変わるとlocalStorageは共有されません。

## 開発・検証

JSONの取得が必要なので、`file://` ではなくHTTPで開きます。

```sh
python -m http.server 8000
# http://localhost:8000/dictionary.html
```

Node.js 18以上とPython 3が必要です。ブラウザテストのみPlaywrightを使います（今回の検証環境はPlaywright 1.62.1 + Chromium）。実行用に `npm install --no-save playwright@1.62.1`、必要に応じ `npx playwright install chromium` を実行してください。アプリの公開動作にnpmやPlaywrightは不要です。

node verify-studio-core.cjs        # v2.0 共通データ構造
node verify-browser-studio.cjs     # v2.0 図鑑・身長比較・相関図・世界観・作品管理（PC幅とスマホ幅、タッチ操作）
python scripts/build_dictionary.py --check
node verify-dictionary.cjs
